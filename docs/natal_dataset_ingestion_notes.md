
# Natal Dataset v1

Purpose:
Compile an existing `Name_2026.jsonl` into a reusable hierarchical natal-analysis package.

Recommended sections in downstream reports:

1. Executive Summary
2. Core Personality
3. Big Three
4. Planet-by-Planet
5. House Analysis
6. Aspect Synthesis
7. Theme Metrics
8. Long-Running 2026 Transit Climate
9. Semantic Operator Analysis
10. Story / Archetype
11. Practical Guidance
12. Technical Appendix

The package should preserve the natal chart exactly and aggregate long-running
transits into reusable evidence structures, analogous to the synastry package.
