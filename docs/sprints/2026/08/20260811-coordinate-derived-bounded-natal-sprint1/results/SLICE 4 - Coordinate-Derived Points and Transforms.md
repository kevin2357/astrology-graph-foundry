# Slice 4 — Coordinate-Derived Points and Transforms

## Outcome

Bounded Natal now assesses antiscia, contra-antiscia, and every configured harmonic
position across the complete birth-time interval. Invariant transformed signs may
enter bounded canonical graph 1.1.0 as derived objects with source-owner lineage;
numeric transform ranges and all variable results remain uncertainty evidence.

## Semantics

- Antiscia uses `180 - longitude`; contra-antiscia uses `180 + longitude`; harmonic
  `n` uses `n × longitude`, all modulo 360 degrees.
- Transforms apply to the conservative unwrapped source proof envelope. They do not
  use an endpoint, midpoint, or representative chart.
- Origin crossings use deterministic circular segments. A harmonic image spanning
  at least one full revolution records full-circle coverage.
- A derived object is eligible only when exactly one transformed sign remains
  possible and its owning base body is present in the invariant graph.
- Derived objects retain sign, transform kind, evidence reference, and owner object
  reference, but no exact longitude or invented motion state.
- Transform configuration participates in bounded calculation profile 1.3.0 and
  its configuration hash.
