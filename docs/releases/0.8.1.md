# Astrology Graph Foundry 0.8.1

**Status:** Qualified release candidate; not published

AGF 0.8.1 is an additive bounded-evidence contract repair over the immutable 0.8.0
release. It does not change astrological calculations, exact-Natal artifacts,
bounded epistemic classifications, graph versions, or established evidence
meaning.

## Contract repair

- The runtime and standalone schema now share one ten-token availability
  vocabulary: eight canonical producer values and two retained compatibility
  aliases.
- Unknown availability values fail at the common evidence-construction boundary.
- The bounded package schema composes the standalone evidence schema at homogeneous
  evidence paths.
- A path-aware iterator discovers common evidence envelopes inside the
  heterogeneous evidence registry without misclassifying supported wrapper and
  branched records.
- Whole-artifact mutation tests cover every homogeneous evidence family and missing
  contract-version discovery.

The evidence contract remains
`agf.bounded_uncertainty_evidence.v1.0.0`, bounded dataset schema remains 1.0.0,
bounded canonical graph remains 1.7.0, and calculation profile remains
`agf.bounded_natal.calculation_profile.v1.12.0`. The repair broadens schema
acceptance to include already-released producer output and does not invalidate
previously schema-valid compatibility spellings.
