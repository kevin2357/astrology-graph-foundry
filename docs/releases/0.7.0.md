# Astrology Graph Foundry 0.7.0

**Status:** Published and download-verified

AGF 0.7.0 adds bounded birth-time Natal generation while preserving exact Natal
contracts. It introduces separate bounded input, dataset, canonical graph,
calculation-provenance, normalization, and interval-proof versions.

Implemented behavior includes minute-by-minute interval evaluation, conservative
longitude/aspect envelopes, invariant-only canonical promotion, complete uncertainty
evidence, reduced capabilities, deterministic chart-scoped IDs, and explicit
rejection by exact-only consumers.

The completed coordinate-derived parity sprint adds the versioned generalized
uncertainty evidence envelope while retaining the established bounded fields. The
release emits bounded canonical graph 1.3.0 and bounded calculation profile 1.5.0.

Exact Birth Data v1, Natal Dataset 1.1.0, canonical graph 1.3.0, and SPC 0.10.0
projection remain unchanged. Bounded projection is not supported by SPC 0.10.0 and
requires a follow-on release.
