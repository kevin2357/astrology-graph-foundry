# Astrology Graph Foundry 0.7.0 Release Candidate

**Status:** Unpublished release candidate; do not pin in production yet

AGF 0.7.0 adds bounded birth-time Natal generation while preserving exact Natal
contracts. It introduces separate bounded input, dataset, canonical graph,
calculation-provenance, normalization, and interval-proof versions.

Implemented behavior includes minute-by-minute interval evaluation, conservative
longitude/aspect envelopes, invariant-only canonical promotion, complete uncertainty
evidence, reduced capabilities, deterministic chart-scoped IDs, and explicit
rejection by exact-only consumers.

Post-qualification Sprint 1 work is adding a versioned generalized uncertainty
evidence envelope while retaining the established bounded fields. Until that work
reaches its final version and release gate, this file describes an evolving
unpublished candidate rather than an immutable artifact.

Exact Birth Data v1, Natal Dataset 1.1.0, canonical graph 1.3.0, and SPC 0.10.0
projection remain unchanged. Bounded projection is not supported by SPC 0.10.0 and
requires a follow-on release. This candidate is not published until separate release
approval creates and verifies an immutable tag, wheel, manifest, checksums, and
GitHub release.

See [Bounded Birth-Time Natal Calculation](../Bounded%20Birth-Time%20Natal%20Calculation.md)
and [Bounded Natal Consumer Handoff](../Bounded%20Natal%20Consumer%20Handoff.md).
