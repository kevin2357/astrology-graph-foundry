# Astrology Graph Foundry 0.8.0

**Status:** Published and download-verified

AGF 0.8.0 is the independently pinnable canonical-calculation baseline. Semantic
Projection Core is no longer an AGF distribution or runtime dependency. AGF emits
canonical graphs, structural evidence, registries, and projection-neutral temporal
source contracts; independently installed downstream systems own projection.

The release removes AGF's projection Python exports, `astro-package project`, the
projection doctor mode, and `projection_adapter.py`. Synastry analysis now emits an
explicit source-factual handoff rather than invoking SPC. This is a breaking
Python/CLI/doctor/view migration, while canonical graph versions remain governed by
their actual source-contract semantics.

## Operational note

The default logging configuration opens `astrology_graph_foundry.log` beneath the
current working directory. Invoke AGF from a writable worker directory or configure
an explicit writable log destination. A read-only artifact/download directory is
appropriate for wheel storage but not as AGF's process working directory.
