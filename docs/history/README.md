# Documentation history

This directory contains implementation records that explain how current Foundry contracts evolved. These files are non-normative and may describe superseded package shapes, commands, ownership boundaries, or implementation status.

## Foundry development records

[`foundry-development/`](foundry-development/) contains completed release notes, migration plans, regression records, the pre-projection semantic-boundary rollout, and the [Foundry 0.6.0 identity/release retrospective](foundry-development/Foundry%200.6.0%20Identity%20and%20Release%20Retrospective.md).

## Projection extraction records

[`projection-extraction/`](projection-extraction/) retains selected material from the period when projection was developed inside Foundry before Semantic Projection Core became an independent repository. Current SPC code and documentation are authoritative for projection behavior. Detailed chronology not retained here remains available through Git history and the SPC repository's own history archive.

## Roadmap archive

[`Ideas and Improvements Archive Through 0.4.2.md`](Ideas%20and%20Improvements%20Archive%20Through%200.4.2.md) preserves completed or superseded roadmap material.
